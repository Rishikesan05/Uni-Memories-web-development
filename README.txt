Uni-Memories - Celebrating IS22/23
==================================

Uni-Memories is a digital archive built for the Information Systems batch (IS22/23) at Sabaragamuwa University of Sri Lanka. It was created to document our journey, from our first meetups to our shared academic milestones.

Sections:
- Interactive Event Timeline.
- Gallery of meetups (Colombo, Kandy, etc.).
- Personal stories and batch memorabilia.
- Integrated university context.

Technical Details:
Built using Vanilla HTML, CSS, and JavaScript with custom animations.
