# Uni-Memories — Celebrating the IS22/23 Journey

**Uni-Memories** is a dedicated web platform built to document and celebrate the shared experiences of the **Information Systems (IS) IS22/23** batch at the **Sabaragamuwa University of Sri Lanka (SUSL)**. It serves as a digital time capsule for batch meetups, university events, and personal connections.

## 🌟 Key Features
- **Interactive Event Slider**: A high-impact hero slider showcasing key meetup highlights from Colombo and Kandy.
- **Meetup Documentation**: Detailed sections for major batch gatherings (Viharamahadevi Park, Peradeniya Garden) with narratives and photo galleries.
- **Academic Context**: Information about the IS program at SUSL and its role in bridging technology and business.
- **Digital Souvenirs**: Dedicated space for "Thank You" cards and digital memorabilia from batch events.
- **Responsive Navigation**: Mobile-friendly navigation with a custom dropdown menu for seamless browsing.

## 🛠️ Technical Stack
- **Frontend**: HTML5, CSS3 (with advanced keyframe animations and responsiveness).
- **Icons**: [Boxicons](https://boxicons.com/) and [Font Awesome](https://fontawesome.com/).
- **Analytics**: Integrated with [Microsoft Clarity](https://clarity.microsoft.com/) for user behavior tracking.
- **Logic**: Vanilla JavaScript (ES6+) for slider mechanics and UI interactions.

## 📁 Repository Structure
- `index.html`: Main landing page with the hero slider and event highlights.
- `meetup.html`: Dedicated gallery and story page for batch meetups.
- `aboutus.html`: Detailed information about the IS22/23 batch and the university.
- `app.js`: Core logic for the interactive slider and menu toggles.
- `assests/`: Comprehensive collection of batch photos and branding assets.

## 🚀 Deployment
This project is a static website and can be deployed instantly to GitHub Pages, Netlify, or Vercel.
